개인정보 처리방침

시행일: 2026년 8월 28일

1. 기본 원칙

싹 메모는 계정을 요구하지 않으며, 개발자가 운영하는 서버·광고·분석 도구를 사용하지 않습니다. 개발자는 앱을 통해 사용자의 개인정보나 메모 내용을 수집, 저장 또는 추적하지 않습니다.

2. 기기에 저장되는 정보

사용자가 작성한 메모, 인식된 받아쓰기 문장, 태그, 즐겨찾기 상태와 임시 초안은 사용자의 기기 안에 저장됩니다. 날짜별 Markdown 파일은 Files 앱에서 사용자가 접근할 수 있는 앱 문서 영역에 생성됩니다.

3. 마이크와 음성 인식

녹음 메모를 선택한 경우에만 마이크와 음성 인식 권한을 요청합니다. 싹 메모는 지원되는 기기에서 Apple의 온디바이스 한국어 음성 인식을 사용하며, 원본 오디오를 파일로 만들거나 보관하지 않습니다. 인식된 텍스트만 사용자가 확인하고 저장할 수 있습니다.

4. 외부 전송과 제3자 제공

싹 메모는 메모, 오디오, 식별자, 사용 기록 또는 진단 정보를 개발자에게 전송하지 않습니다. 광고 네트워크나 제3자 분석 SDK도 포함하지 않습니다. 운영체제의 백업이나 사용자가 선택한 파일 제공자에 의해 데이터가 동기화되는 경우에는 해당 Apple ID 및 서비스 설정과 각 제공자의 정책이 적용됩니다.

5. 보관과 삭제

메모는 사용자가 삭제할 때까지 기기에 남습니다. 앱 안의 휴지통에서 영구 삭제할 수 있으며, 앱을 삭제하면 앱 컨테이너의 로컬 데이터도 삭제됩니다. Files 앱이나 백업에 별도로 남은 복사본은 사용자가 해당 위치에서 직접 삭제해야 합니다.

6. 권한 변경

마이크와 음성 인식 권한은 언제든지 iPhone의 설정 앱에서 변경할 수 있습니다. 권한을 허용하지 않아도 타이핑 메모와 보관함 기능을 사용할 수 있습니다.

7. 방침 변경

기능이나 데이터 처리 방식이 달라지면 이 문서를 갱신하고 시행일을 변경합니다. 중요한 변경은 앱 업데이트 설명이나 지원 페이지를 통해 안내합니다.
